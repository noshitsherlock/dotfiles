# dotfiles

Sets up a new Mac to look and work like the old one.

```
Brewfile              brew formulae, casks, fonts (generated by snapshot)
Brewfile.extra        apps installed outside brew on the old Mac (hand-maintained)
home/                 dotfiles, copied into $HOME (__HOME__ -> your home dir)
templates/            configs containing secrets; ${VARS} filled from private/secrets.env
skills/               agent skills, copied to ~/.agents, ~/.claude, ~/.codex, ~/.copilot, ~/.gemini
macos.sh              macOS defaults
install.sh            runs everything
scripts/snapshot.sh   re-captures the current Mac into this repo
private/              NOT committed: secrets, repo list, app prefs, launch agents, Caddyfile
```

## On the old Mac (right before switching)

```sh
./scripts/snapshot.sh   # refresh everything
git diff                # review, then commit + push
```

Copy `private/` to the new Mac via AirDrop or 1Password. It contains API keys, so don't email it or commit it.

Also export these by hand (they can't be captured from files):

- **Raycast**: Settings → Advanced → Export (`.rayconfig`, includes snippets, quicklinks and hotkeys)
- **Obsidian**: vaults are just folders; make sure they're synced or copied
- **Browser** (Brave): turn on Sync, or export bookmarks
- **SSH key**: generate a new one on the new Mac rather than copying the old one

## On the new Mac

```sh
xcode-select --install
git clone https://github.com/noshitsherlock/dotfiles.git ~/Development/dotfiles
cd ~/Development/dotfiles
# put private/ here
./install.sh            # or individual steps: ./install.sh dotfiles skills claude
```

Steps: `brew shell node python dotfiles skills claude private macos editors`

Casks that need admin rights (Docker, Logi Options+, etc.) will trigger Admin By Request prompts.

### Afterwards, by hand

1. **Sign in**: App Store (before `brew bundle` for Amphetamine/Xcode), 1Password, Slack, Brave, Spotify, Telegram, Obsidian, Figma, Miro, Zoom
2. **GitHub**: `gh auth login`, then `ssh-keygen -t ed25519 && gh ssh-key add ~/.ssh/id_ed25519.pub`. Re-run `./install.sh private` to clone any repos that failed.
3. **AI agents**: log in to each: `claude`, `codex login`, `gemini`, `copilot`, `opencode auth login`, `pi`. Also sign in to the Claude, ChatGPT and Antigravity desktop apps.
4. **Raycast**: import the `.rayconfig`
5. **tmux**: inside tmux press `prefix + I` if any plugins are missing
6. **Permissions**: grant Accessibility / Screen Recording to Raycast, Rectangle, Mouseless, Hidden Bar, Stats, Ghostty when macOS prompts
7. **Forefront Sparks** (`claude-sparks`, `~/.config/sparks`): reinstall from the internal source; it has its own key
8. **IT-managed apps** (Office, Teams, OneDrive, PaperCut): install via Company Portal
