# dotfiles

Sets up a new Mac from scratch to look and work like the old one. Migration Assistant isn't an option because of Admin By Request, so everything is scripted here instead.

## What's in the repo

```
Brewfile                brew taps, formulae, casks and fonts (generated by snapshot.sh)
Brewfile.extra          apps installed outside brew on the old Mac, plus rtk and App Store apps (hand-maintained)
vscode-extensions.txt   VS Code extensions (generated by snapshot.sh)
home/                   dotfiles copied into $HOME (__HOME__ is replaced with your home dir)
templates/              configs that contain secrets; ${VARS} are filled from private/secrets.env
skills/                 agent skills, copied to ~/.agents, ~/.claude, ~/.codex, ~/.copilot and ~/.gemini
macos.sh                macOS defaults (keyboard, Finder, Dock, screenshots, Terminal)
install.sh              runs the install steps below
scripts/snapshot.sh     re-captures the current Mac into this repo
private/                NOT committed (gitignored), see below
```

### home/

| Area | Files |
| --- | --- |
| Shell | `.zshrc`, `.zprofile`, `.p10k.zsh` (Oh My Zsh + Powerlevel10k, Starship, eza aliases) |
| Git / GitHub | `.gitconfig`, `.config/git/ignore`, `.config/gh/config.yml` |
| Terminals | Ghostty, WezTerm, tmux (`.tmux.conf`, `.config/tmux`), herdr, btop |
| Editor | VS Code `settings.json` |
| Claude Code | `settings.json` (hooks, plugins, ccstatusline status line), `CLAUDE.md`, `RTK.md`, `rules/`, `hooks/` (rtk, herdr), `statusline-command.sh` |
| Codex | `AGENTS.md`, `hooks.json`, `hooks/` (rtk), herdr hook |
| Other agents | Copilot CLI, Gemini CLI, opencode (`tui.jsonc`, plugins), Pi, qmd, ccstatusline |

### templates/

These configs contain API keys, so the repo stores them with `${VARS}` in place of the keys:

- `.codex/config.toml`: Codex model, context7 MCP, plugins
- `.config/opencode/opencode.json`: Forefront Sparks provider and MCP
- `.pi/agent/mcp-adapter.json`: Sparks MCP for Pi

### private/ (never committed)

`snapshot.sh` writes this folder, and you copy it to the new Mac by hand (AirDrop or 1Password, not email):

- `secrets.env`: Context7 and Sparks keys and URLs used to fill the templates
- `repos.txt`: git repos under `~/Development` and `~/Projects`, cloned on install
- `prefs/`: app settings for Rectangle, Itsycal, Stats, Hidden Bar, iTerm2 and MeetingBar
- `claude-settings.local.json`: Claude Code's local permission allowlist
- `LaunchAgents/`: background services (meeting-calendar)
- `Caddyfile`: local Caddy reverse proxy

### Left out on purpose

- **Headroom, Serena and Cursor**: not wanted on the new Mac. `snapshot.sh` strips them out, including the `ANTHROPIC_BASE_URL` Headroom proxy setting.
- **IT-managed apps** (Microsoft 365, Teams, OneDrive, PaperCut, NXPowerLite): install through Company Portal.
- **SSH keys**: create a new key on the new Mac.

## Before switching (on the old Mac)

```sh
./scripts/snapshot.sh   # refresh Brewfile, home/, templates/, skills/ and private/
git diff                # review, then commit and push
```

Then copy `private/` to the new Mac and export these by hand:

- **Raycast**: Settings → Advanced → Export (`.rayconfig`, includes snippets, quicklinks and hotkeys)
- **Obsidian**: vaults are plain folders, so make sure they're synced or copied
- **Brave**: turn on Sync, or export bookmarks

## Setting up the new Mac

Sign in to the App Store first, so Amphetamine and Xcode can install.

```sh
xcode-select --install
git clone https://github.com/noshitsherlock/dotfiles.git ~/Development/dotfiles
cd ~/Development/dotfiles
# put private/ here
./install.sh                    # every step
./install.sh dotfiles skills    # or only some steps
```

`install.sh` is safe to re-run. Any existing file it overwrites is backed up to `~/.dotfiles-backup/<timestamp>/`.

| Step | What it does |
| --- | --- |
| `brew` | Xcode CLT, Homebrew, `Brewfile` and `Brewfile.extra` |
| `shell` | Oh My Zsh, Powerlevel10k, zsh plugins, tmux plugin manager |
| `node` | fnm with Node 22 (default) and 24, pnpm, bun, global npm packages (codex, gemini-cli, pi, qmd, bigpowers) |
| `python` | uv and claude-monitor |
| `dotfiles` | copies `home/` into `$HOME`, fills `templates/` from `private/secrets.env`, installs opencode and tmux plugins |
| `skills` | copies `skills/` to every agent and links the bigpowers skills into `~/.claude/skills` |
| `claude` | Claude Code plugins (vercel, frontend-design, typescript-lsp, codex) and the context7 MCP server |
| `private` | Claude permissions, app settings, repo clones, Caddy, LaunchAgents (skipped if there's no `private/`) |
| `macos` | runs `macos.sh` |
| `editors` | VS Code extensions |

Casks that need admin rights (Docker, Logi Options+, etc.) will trigger Admin By Request prompts.

Forefront's organization skills aren't in this repo. They sync to `~/.claude/skills/synced` once you log in to Claude Code with your Forefront account.

### Afterwards, by hand

1. **Sign in**: 1Password, Slack, Brave, Spotify, Telegram, Obsidian, Figma, Miro, Zoom
2. **GitHub**: `gh auth login`, then `ssh-keygen -t ed25519 && gh ssh-key add ~/.ssh/id_ed25519.pub`. Re-run `./install.sh private` to clone any repos that failed.
3. **AI agents**: log in to `claude`, `codex login`, `gemini`, `copilot`, `opencode auth login` and `pi`, and to the Claude, ChatGPT and Antigravity desktop apps
4. **Raycast**: import the `.rayconfig`
5. **tmux**: inside tmux, press `prefix + I` if any plugins are missing
6. **Permissions**: allow Accessibility / Screen Recording for Raycast, Rectangle, Mouseless, Hidden Bar, Stats and Ghostty when macOS asks
7. **Forefront Sparks** (`claude-sparks`, `~/.config/sparks`): reinstall from the internal source; it has its own key
8. **IT-managed apps**: install through Company Portal
